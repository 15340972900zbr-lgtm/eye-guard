# 护眼工具使用手册

护眼工具用摄像头统计眨眼和用眼时间、判断相对距离，并按你设置的条件发出提醒。摄像头画面和关键点在本机内存中处理。安装所需依赖和模型后，应用可以离线运行。

| 版本 | 适用设备 | 功能 |
| --- | --- | --- |
| macOS | Apple Silicon Mac | 眨眼、连续用眼、相对距离、头前倾提醒 |
| Windows 试用版 | Windows 10 / 11，Intel 或 AMD x64 | 眨眼、连续用眼、相对距离 |

## 1. 安装并启动

### macOS

安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)，从 GitHub 克隆本项目。打开终端，进入项目目录后依次运行：

```sh
uv sync
uv run python scripts/download_model.py
uv run eye-guard
```

前两步会安装依赖、下载模型。以后在同一个目录运行 `uv run eye-guard` 即可。顶部菜单栏出现**单色眼睛图标**后，点击图标并选择「启动监控」。

首次调用摄像头时，按 macOS 提示授权。如果此前拒绝过，在「系统设置 → 隐私与安全性 → 相机」里查看并开启启动程序所用终端的摄像头权限，再重启终端和应用。

### Windows

1. 打开 [Windows 试用版发布页](https://github.com/15340972900zbr-lgtm/eye-guard/releases/tag/windows-v0.1.0)，下载 `EyeGuard-Setup-Windows-x64.exe`，在 Windows 电脑上双击安装。安装包已包含 Python 和视觉模型。
2. 在「开始」菜单搜索「护眼工具」。启动后在任务栏右下角找到眼睛图标，也可以点箭头查看隐藏的图标。
3. 右键点击图标，选「启动 / 恢复监控」。需要时在 Windows 的相机隐私设置中开启桌面应用的相机访问权限。

Windows 试用版安装包未签名，Windows 真机上的安装、相机与通知流程仍待验证。

## 2. 看状态和校准距离

- **查看统计**。macOS 点开菜单栏的眼睛图标，查看「状态」。Windows 在托盘里选「查看当前统计」。眨眼次数是本次累计值，括号内的「次/分」看的是近期频率。刚启动或镜头暂时没有捕捉到你时，读数可能偏低。
- **校准距离**。坐到你平时觉得舒服的位置，点击「校准距离」，保持坐姿直到采样结束。校准基准的指数是 **1.0**。指数高于 1 通常表示脸比校准时更靠近摄像头，低于 1 通常表示更远。这个指数是人脸框面积比。
- **暂停或退出**。选择「暂停监控」可释放相机，恢复后重新开始累计连续用眼时段。选择「退出」可结束应用。
- **清零**。选择「重置统计」可清空眨眼和用眼时间统计。

## 3. 开启头前倾提醒（macOS）

1. 启动监控，正对摄像头，确保**双耳和双肩都入镜**。
2. 自然坐直、放松肩膀，点「坐姿提醒 → ① 校准坐直姿势」，保持几秒，等菜单显示「待校准前倾界线」或收到提示。
3. 肩膀尽量保持原位，头往前伸到你希望被提醒的位置，点「② 校准前倾提醒界线」，保持几秒。
4. 校准成功后，头部相对双肩持续前伸到设定界线约 3 秒时，会收到坐直、放松肩膀的提醒。两次姿势差别过小时，重新做第 3 步。

暂停监控会保留本次坐姿校准。「关闭并清除坐姿校准」或退出应用后，需要重新校准。移动摄像头或更换座位后也可重新校准。头前伸是摄像头估计值，正面画面对圆肩和背部弯曲程度的判断有限。

## 4. 设置其他提醒

休息、眨眼和距离阈值默认留空。你可以只启用自己需要的提醒。

- **macOS**。若项目目录下还没有 `config.toml`，把 `config.example.toml` 复制为 `config.toml`，再用文本编辑器打开。
- **Windows**。在托盘菜单选择「编辑配置（重启后应用）」。

对应行的 `#` 表示注释。把要启用的行取消注释，填写自己选择的值，保存后重启工具。距离阈值和校准处于同一指数尺度。

| 配置项 | 触发条件 |
| --- | --- |
| `continuous_remind_minutes` | 连续用眼达到设定分钟数 |
| `blink_rate_remind_per_min` | 采样达到统计窗口后，近期眨眼次数低于设定的次/分 |
| `proximity_too_close` | 完成校准，距离指数高于过近阈值 |
| `proximity_too_far` | 完成校准，距离指数低于过远阈值 |

同类眨眼或距离提醒默认至少间隔 5 分钟。macOS 的坐姿提醒由菜单里的两步校准开启。

## 5. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 看不到图标 | Mac 看屏幕顶部菜单栏，Windows 看任务栏右下角的隐藏图标。 |
| 相机打不开 | 检查系统相机权限。关闭可能占用摄像头的视频会议软件，再尝试恢复监控。 |
| 找不到模型（macOS） | 在项目目录运行 `uv run python scripts/download_model.py`，然后重新打开应用。 |
| 总提示双耳、双肩入镜 | 把摄像头移到能正面拍到上半身的位置，避免遮挡，重新校准。 |
| 一直收不到提醒 | 检查是否设定了相应阈值或完成了坐姿校准，以及系统通知权限和勿扰模式。要单独测试通知，可点「校准距离」并等完成提示。 |
