护眼工具 Windows 版 0.1.0

系统：Windows 10 / 11，Intel 或 AMD 64 位。
安装包内含 Python、视觉依赖和人脸关键点模型。安装和使用均可在断网时进行。
安装到当前用户目录，从「开始」菜单搜索「护眼工具」即可再次打开。

首次使用
1. 在任务栏右下角找到蓝绿眼睛图标。图标也可能在「显示隐藏的图标」里。
2. 右键选「启动 / 恢复监控」。相机关闭时，可在 Windows 设置的「隐私与安全性」中允许桌面应用访问相机。
3. 可以悬停查看数据，或点击图标查看当前统计。
4. 保持舒服的坐姿，选「校准距离」。距离指数是当前人脸框面积与校准时的比值，大于 1 通常表示更近。
5. 暂停或退出会释放摄像头。应用只累计成功检测到人脸的时间，监控中断后会重新采集眨眼频率窗口。

提醒
休息、眨眼和距离提醒阈值由你设置，默认关闭。右键「编辑配置」可打开本地配置，保存后重启应用。
任务栏提醒使用 Windows 的通知区。通知关闭时，依然可以通过托盘菜单查看当前统计。

卸载
在 Windows「已安装的应用」里选择「护眼工具」并卸载。更改过的个人设置保留在 %LOCALAPPDATA%\EyeGuard\config.toml。
运行时没有联网功能。摄像头画面和面部关键点只在内存中处理。
